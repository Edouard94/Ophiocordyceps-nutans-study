# Raw data

This folder is reserved for additional raw inputs related to the *Ophiocordyceps nutans* study.

## Current status

- No raw data files are currently tracked here (only this README).
- Illumina input reads are stored under `amplicon processing/Illumina/Julia_data/`.
- ONT input and intermediate FASTQ files are stored under `amplicon processing/ONT/` and tracked with Git LFS.

## Accessing large sequence files

After cloning, install Git LFS and retrieve the sequence objects with:

```bash
git lfs install
git lfs pull
```
